Q. 우리 회사가 어떤 일을 하는 회사인지 아시나요?
- 공공·금융·제조 분야를 중심으로 Java/JSP 기반 시스템 구축과 SI·유지보수 업무를 수행하는 회사

Q. 블로그에서 본 프로젝트 중 관심 있었던 프로젝트는?
- 금융권 차세대 시스템 구축 프로젝트가 관심 있었고, 대규모 업무 시스템을 Java로 어떻게 설계하고 운영하는지 궁금했습니다.

Q. SI 프로젝트에서 개발자의 역할은 무엇이라고 생각하나요?
- 고객의 요구사항을 분석하고 설계·개발·테스트·배포와 유지보수까지 프로젝트 전체 과정에서 시스템을 구현하는 역할이라고 생각합니다.

Q. Java와 JSP를 사용해 본 경험은?
- Java/Spring Boot로 REST API와 JPA를 활용한 백엔드 프로젝트를 진행했고 JSP도 기본적인 MVC 구조와 화면 개발 방식을 학습했습니다.

Q. Spring과 JSP의 관계를 설명해보세요.
- Spring이 비즈니스 로직과 요청 처리를 담당하고 JSP는 서버에서 데이터를 받아 HTML 화면을 생성하는 View 역할을 합니다.

Q. MVC 패턴을 설명해보세요.
- Model은 데이터와 비즈니스 로직, View는 화면, Controller는 사용자 요청을 받아 Model과 View를 연결하는 구조입니다.

Q. MyBatis와 JPA의 차이는?
- MyBatis는 SQL을 직접 작성해 세밀하게 제어하는 방식이고 JPA는 객체 중심으로 개발하면서 SQL 작성을 줄일 수 있는 ORM 기술입니다.

Q. 트랜잭션이란?
- 여러 DB 작업을 하나의 작업 단위로 묶어서 모두 성공하거나 하나라도 실패하면 전체를 롤백하도록 보장하는 기능입니다.

Q. DB에서 JOIN을 어떻게 사용하는가?
- 여러 테이블에 분리되어 있는 데이터를 공통 컬럼을 기준으로 연결해서 조회하는 SQL 기능입니다.

Q. SI 프로젝트에서 유지보수할 때 중요한 것은?
- 기존 시스템의 구조와 업무 로직을 정확히 이해하고 장애가 발생하지 않도록 영향 범위를 확인하면서 안정적으로 수정하는 것이 중요하다고 생각합니다.
